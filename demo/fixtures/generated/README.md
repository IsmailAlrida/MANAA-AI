# Generated fictional public OSINT fixtures

Deterministic static captures for four fictional cases. All records are public-source-style text artifacts using reserved `.test` hosts. No live scanning, requests, ads, forms, redirects, customer data, private provider imports, or transactions are implemented. The four evidence paths converge through public portfolio/ad disclosure, marketplace terms, and independent business directory captures.

Run `python3 generate_fixtures.py` to generate. Run `python3 generate_fixtures.py --check` to compare expected output without writing. Uses only the Python standard library.
