# Generated fictional public OSINT fixtures

Deterministic static captures for four fictional cases, including one explicitly assumed-authorized police internal API mock record. All records use reserved `.test` hosts. No real internal API call, live scan, customer/transaction record, or real person data is included. The four evidence paths converge through public portfolio/ad disclosure, marketplace terms, and independent business directory captures. Ticket reports include final-stage authored Arabic and English variants with shared IDs and cited evidence; source captures remain unchanged.

Run `python3 generate_fixtures.py` to generate. Run `python3 generate_fixtures.py --check` to compare expected output without writing. Uses only the Python standard library.
